# ADR-0022: Governance and security council

- **Status:** Proposed
- **Date:** 2026-09-16
- **Blueprint refs:** sections 30, 38.22

## Context
Section 30: early-stage security council multisig with explicit signer roles, timelocked upgrades, public notices, narrow emergency path, postmortems. No token merely for governance.

## Decision (leaning)
5-of-9 security council (internal roles documented privately), 48 h timelock on non-emergency upgrades, 2-of-9 emergency pause limited to `EmergencyControls`, postmortem published within 7 days of any emergency action. Revisit decentralised governance only when it improves credible neutrality.
